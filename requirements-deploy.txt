# Production dependency set for the container build.
#
# The repo's own requirements.txt is left untouched, but it cannot be used as-is
# for a container:
#   * it is completely unpinned, so builds are not reproducible;
#   * it lists `psycopg2` (source distribution), which needs gcc + libpq-dev in
#     the image; `psycopg2-binary` is the wheel and is what you want here;
#   * it has no WSGI server and no async worker, so there is nothing to run
#     Flask-SocketIO with in production.
#
# Pins below match the versions the repo's unpinned names resolve to as of
# 2025, verified against each project's own dependency metadata.
